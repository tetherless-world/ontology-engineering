The workbook documents the project's conversation move classes, relationships, states, provenance concepts, and state assignment vocabulary. The `PrioritizedTerms` worksheet records preferred labels, definitions, sources, scope and usage notes, examples, dependencies, and team contributions. The `Sources` worksheet contains the supporting references.

The Week 10 workbook uses **conversation move** for the persistent contribution represented in the ontology. Its main move types are Information Request, Issue, Option, Claim, Expressed Position, and Outcome. State Assignment records connect moves with states, effective utterances, evidence, and preceding assignments. See the [conceptual model and executable ontology](ontology.html) for the class hierarchy and property relationships.

The Week 10 workbook lists 64 terms. Compared with Week 9, it adds Deliberative Dialogue and uses the implemented `hasPositionTowards` label. It also drops the SupportedContested state, which the current schema no longer defines. Rows now begin with the conversation-level concepts, and the source columns state what each source establishes.

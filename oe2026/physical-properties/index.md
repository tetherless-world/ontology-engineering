## Reasoning About Action Feasibility from Physical Properties

Our project develops an ontology for explainable reasoning about whether an object can physically support an action. It connects the physical features of candidate objects and their parts, target conditions, and action requirements. The initial scope is **CUT in everyday kitchen contexts**, assuming the capabilities of an ordinary human actor.

An assessment connects a candidate, target, and action so that feasibility can be evaluated from explicitly represented physical evidence. Object names and conventional functions are not evidence for feasibility. The intended outcomes distinguish feasible, infeasible, and insufficient-information cases, with explanations grounded in the represented features and requirements. Physical features are supplied as structured information; object recognition and visual feature estimation are outside the scope.

The project supports three questions: evaluating one candidate and target, comparing alternative candidates, and examining different part structures such as a knife edge and interacting scissor blades. These are the project's reasoning goals; the linked ontology and use case document the current implementation and its scope.
